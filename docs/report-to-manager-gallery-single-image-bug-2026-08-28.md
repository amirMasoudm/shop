## یافته

`src/main/resources/templates/CL.html` (قالبِ صفحهٔ محصول) در هر سه جایی که تصویر
رندر می‌کند، فقط `images[0]` را می‌خواند:

```
line 1347:  th:src="${p.images != null and !p.images.isEmpty() ? p.images[0] : ...}"
line 1403:  th:src="${prod.images != null and !prod.images.isEmpty() ? prod.images[0] : ...}"
line 1860:  const mainImg = (p.images && p.images.length > 0) ? p.images[0] : '';
```

هیچ لوپ/گالری/thumbnail برایِ `images[1]`, `images[2]`, ... وجود ندارد.

## اثر

**این باگِ کلِ کاتالوگ است، نه یک محصولِ خاص.** هر محصولی که در بسته‌های محتواییِ
گذشته با ۲ تا ۴ عکس ساخته شده (اکثرِ کاتالوگ، از سشن‌هایِ متعددِ چت ب) — عکسِ اول را
مشتری می‌بیند، بقیه در دیتابیس/API هست ولی هیچ‌وقت رندر نمی‌شود. تأیید شد با
GET مستقیمِ HTML یک محصولِ ۲عکسی: فقط یک URL در کلِ صفحه بود، هرچند API دو تا
برمی‌گرداند.

## دامنه‌اش خارج از این چت است

اصلاحش تغییرِ قالبِ صفحهٔ محصول (سمتِ frontend/Thymeleaf) است، نه دادهٔ محصول —
یعنی کارِ چت الف، نه چت ب. فقط ثبت می‌کنم که دیده شود؛ خودم دست نزدم.

## پیشنهاد برایِ تسکِ آینده

هر وقت صلاح دیدید، یک پرامپت برایِ الف بنویسید که هر سه نقطه بالا یک گالریِ
واقعی (لوپِ رویِ `images`، با thumbnailهایِ قابلِ کلیک) رندر کنند — نه فقط
اولین عکس. این باگ روی صدها محصول اثر دارد، پس اولویتش احتمالاً بالاست.
