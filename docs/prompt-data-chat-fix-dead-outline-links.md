## چه شد

در بستهٔ B-۳ درست گرفتی که لینکِ سرفصلِ مقاله‌های MTCTCE به `MTCUME_Outline.pdf`
می‌رود نه MTCTCE. مدیر بررسی کرد و معلوم شد مسئله بزرگ‌تر است:

**هر پنج PDFِ سرفصل روی سایتِ خودِ میکروتیک `404` است** — نه فقط MTCUME:

```
MTCNA_Outline.pdf   404
MTCWE_Outline.pdf   404
MTCRE_Outline.pdf   404
MTCTCE_Outline.pdf  404
MTCUME_Outline.pdf  404
```

میکروتیک مسیرِ `mikrotik.com/pdf/` را برداشته. یعنی حتی لینک‌های **درستِ** MTCRE هم
مرده‌اند، و سؤالِ «کدام PDF درست است» بی‌موضوع شده.

## کار

هر لینکی که به `mikrotik.com/pdf/…_Outline.pdf` می‌رود، به این تغییر کند:

```
https://mikrotik.com/training/about
```

صفحهٔ رسمیِ آموزشِ میکروتیک است، `200` می‌دهد، و همهٔ مدرک‌ها را معرفی می‌کند. این
هم ۲۹ لینکِ مرده را درست می‌کند، هم ناهمخوانیِ MTCUME/MTCTCE را — چون دیگر به
PDFِ یک دورهٔ خاص اشاره نمی‌کند.

**خودِ جمله («سرفصل‌های این دوره») بماند.** فقط `href` عوض شود.
