## اول — یک اصلاحِ دوخطی از C-۳ (تقصیرِ مدیر)

متنِ دو مقاله این را ادعا می‌کند:

```
huawei-rtn-epla-feature-principle-overview   «این کلیپِ آموزشیِ شرکت داده‌نما…»
huawei-rtn-feature-animation-eth-oam         «این کلیپِ آموزشیِ شرکت داده‌نما…»
```

در گزارش نوشتی توضیحِ آپارات «هوآوی» را **تأیید نکرد**، پس داده‌نما ثبتشان کردی. ولی
«هوآوی تأیید نشد» با «داده‌نما تأیید شد» یکی نیست — توضیح دربارهٔ سازنده **ساکت**
بود. و عنوانشان (`HUAWEI RTN Feature Animation…`) دقیقاً نامِ سریِ رسمیِ انیمیشن‌های
هوآوی است.

**این تقصیرِ قاعدهٔ مدیر بود**، نه اجرای تو: نوشته بودم «سازنده را از توضیح بگیر»،
ولی نگفته بودم وقتی توضیح ساکت است چه کنی.

**اصلاح:** در این دو مقاله، ادعای سازنده برود و جمله خنثی شود:

```
«این انیمیشنِ آموزشی (با زیرنویسِ فارسی) …»
```

فقط متن؛ اسلاگ دست نخورد، کادرِ ریدایرکت نباید بیاید.

**قاعدهٔ کامل از این به بعد:** توضیح گفت هوآوی → هوآوی. گفت داده‌نما → داده‌نما.
**ساکت بود → هیچ سازنده‌ای ادعا نکن.**

## 🔴 سه نکتهٔ این بسته

### یک — اولین بارِ بستهٔ C که ریدایرکتِ وردپرسی درگیر است

سه مقاله مقصدِ ریدایرکتِ وردپرسی‌اند. اگر اسلاگشان را عوض کردی، **«بله» را حتماً
بزن** و بعد آدرسِ **وردپرسیِ** آن‌ها را هم باز کن (نه فقط اسلاگِ قبلیِ بلاگ را) —
باید با **یک پرش** به آدرسِ تازه برسد. سرور زنجیره را خودش صاف می‌کند، ولی این اولین
بار است که در بستهٔ C امتحانش می‌کنیم.

### دو — دو مقالهٔ «تیونینگ آنتن» ممکن است یک ویدیو باشند

در بلاگ دو مقاله هست، و **هر دو** مقصدِ ریدایرکتِ وردپرسی‌اند:

```
آموزش-تیونینگ-آنتن-های-مایکروویو   ->  aparat.com/v/KJz8B  (zende, 200)
دانلود-آموزش-تیونینگ-آنتن-مایکروویو ->  link-e CDN-e morde   <- in baste
```

اولی لینکِ **صفحهٔ** آپارات دارد و زنده است؛ دومی (این بسته) لینکِ CDNِ مرده.

⚠️ اگر ویدیویی که برای دومی پیدا کردی **همان `KJz8B`** بود، یعنی دو مقاله یک ویدیو
را نشان می‌دهند. در آن حالت **تمایزِ ساختگی نساز** و آن مقاله را دست‌نخورده رها کن —
در گزارش بنویس تا مالک تصمیم بگیرد. (حذف مجاز نیست؛ تصمیمِ مالک است.)

و اگر «دانلود» را از اسلاگش برداشتی، دقت کن: `آموزش-تیونینگ-آنتن-مایکروویو` فقط با
یک «های» از آن یکی فرق دارد. دو آدرسِ تقریباً یکسان برای دو مقالهٔ تقریباً یکسان،
خودش مشکل است.

### سه — بیشترِ اسلاگ‌ها روی **کلمهٔ کامل** بریده شده‌اند

همان درسِ C-۱:

```
…-از-دیدگاه      <- «هوآووی» qeychi shode
…-بعد-از         <- «سال ۲۰۰۰ تا کنون» qeychi shode
…-در-مقایسه      <- «با فیبر نوری» qeychi shode
…-توسط-ش         <- «شرکت داده نما»
…-و-افز          <- «افزایش ظرفیت ها»
…-و-کاربرده      <- «کاربردها» (ghalat-e emla'i ham hast)
```

و `مایکرویوو` (با دو «و») در عنوان و اسلاگِ «انواع ایستگاه‌ها» غلطِ املایی است.

## مقالهٔ «برگزاری دوره وایرلس و مایکروویو»

تنها مقالهٔ این بسته با متنِ واقعی (۹۹ واژه): گزارشِ یک دورهٔ سه‌روزه در **تهران**
با مدرسی **آقای مهندس شیخ ابومسعودی**، و **دو** لینکِ CDNِ مرده.

- گزارشِ گذشته بماند، نه فراخوان
- 🔴 **نامِ مدرس بماند** — طبقِ قاعدهٔ اطلاعاتِ تماس، نامِ افراد دست نمی‌خورد
- هر دو ویدیو را در کانال بگرد

## کارِ هر مقاله

همان روشِ C-۱ تا C-۳. لینکِ **صفحه**، هرگز CDN. مفهومِ فنی نساز. سازنده فقط طبقِ
توضیحِ آپارات — و اگر ساکت بود، هیچ.

هر هشت مقاله **منتشرشده‌اند** → هر تغییرِ اسلاگ → **«بله»**.
