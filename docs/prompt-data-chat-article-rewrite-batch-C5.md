قبلیِ بلاگ) — باید با **یک پرش** به آدرسِ تازه برسد.

## 🔴 سه تلهٔ این بسته

### یک — تلهٔ `-2`ِ C-۱، دوباره

```
…-دوره-جامع-وایرلس-دا     ->  onvan: «بخش DOVVOM»
…-دوره-جامع-وایرلس-دا-2   ->  onvan: «بخش AVVAL»   <- -2 ruye bakhsh-e avval
```

**دقیقاً همان الگوی C-۱:** دنبالهٔ `-2` روی **بخشِ اول** نشسته. و این‌بار **هر دو
مقصدِ ریدایرکتِ وردپرسی‌اند** — یعنی اگر ضربدری شوند، دو آدرسِ باسابقه در گوگل
به قسمتِ اشتباه می‌روند.

هر اسلاگ را از روی **عنوانِ خودِ همان مقاله** بساز. بعد از ذخیره، هر **چهار** آدرس را
بسنج — دو اسلاگِ قدیمیِ بلاگ و دو مسیرِ وردپرسی — و مطمئن شو «بخش اول» به «بخش
اول» می‌رسد.

### دو — دو دیشِ وایمکس‌نیر، دو محصولِ متفاوت

```
دیش 33DBI   ->  ۳۳ دسی‌بل
دیش ۳۲DBi   ->  ۳۲ دسی‌بل
```

عنوانشان تقریباً یکی است ولی **دو آنتنِ جدا**‌اند. ویدیوی هرکدام را جدا پیدا کن و
عددِ دسی‌بل را جابه‌جا نکن. هر دو محصول در فروشگاه هستند
(`SP62-33D Low-band` و `SP62-32D HP`)، ولی **لینکِ محصول اضافه نکن** مگر ویدیو مدلِ
دقیق را نشان دهد — «۳۳ دسی‌بلِ وایمکس‌نیر» ممکن است بیش از یک مدل باشد.

### سه — Ligowave «بخش اول» — بخشِ دومی در سایت نیست

در کلِ بلاگ فقط «آموزش کار با Ligowave Link calc- **بخش اول**» هست. اگر در آپارات
بخشِ دوم هم پیدا کردی، در گزارش بنویس (ویدیوی وصل‌نشدهٔ دیگری است، مثلِ QinQ). اگر
ویدیو واقعاً «بخش اول» است، عنوان همان بماند؛ **آن را برای قشنگی حذف نکن.**

## اسلاگ‌ها

بریدگی‌ها — چند تا روی **کلمهٔ کامل**:

```
…-رادیوی-شرک           <- «شرکت Cambium Network مدل ePMP»
…-دوره-جامع-وایرلس-دا  <- «داده نما بخش …»
…-در-ارتباطات-وای      <- «وایرلس»
…-رادیو-و-مودم-های     <- «کمپانی راکام» qeychi shode (kalame-ye kamel)
```

و «دانلود» از اول هر اسلاگ و عنوان برود. نیم‌فاصله در عنوان، خط‌تیره در اسلاگ.
