# چک‌لیست تحقیق کلمات + آف‌پیجِ رقبا — کاملاً رایگان (جایگزینِ Semrush)

> **چرا رایگان؟** Semrush برای بازار ایران/فارسی دیتای کم‌عمقی دارد و پرداختش هم دردسر است. مهم‌تر: در فاز ۲ فهمیدیم بک‌لینکِ رقبا **۸۹٪ تلگرام** (بی‌ارزش) است، پس آف‌پیجِ عمیق ROI پایینی دارد. استکِ رایگانِ زیر همان خروجی‌ها را می‌دهد، برای ایران دقیق‌تر.
>
> **زمانِ لازم:** حدود ۲–۳ ساعت، یک‌باره. سه رقیب واقعیِ هدف: **irmikro.com، arghavannet.com، mrshabake.com** (بقیه در فاز ۲ ضعیف ارزیابی شدند).

---

## بخش A — حجم و سختی کلماتِ ما (مهم‌ترین بخش)
**ابزار: Google Keyword Planner** (رایگان؛ فقط یک اکانت Google Ads می‌خواهد — نیازی به تبلیغِ فعال/پرداخت نیست).

1. برو به `ads.google.com` → یک اکانت بساز → از منو: **Tools → Planning → Keyword Planner**. اگر خواست کمپین بسازی، گزینه‌ی **«Switch to Expert mode»** و بعد **«Create an account without a campaign»** را بزن (تا پول درگیر نشود).
2. **زبان/موقعیت را روی «Persian» و «Iran» تنظیم کن** (خیلی مهم — پیش‌فرض انگلیسی/آمریکا اشتباه است).
3. **«Get search volume and forecasts»** را باز کن → کلِ ۴۱ کلمه‌ی ستونِ کلمه‌ی `docs/keyword-map.csv` را کپی/پیست کن.
4. برای هر کلمه این‌ها را بردار: **Avg. monthly searches** (بازه‌ای است، اشکالی ندارد) و **Competition** (Low/Med/High — این «رقابتِ تبلیغاتی» است، نه دقیقاً KD، ولی سیگنالِ خوبی است).
5. خروجی را در `keyword-map.csv` سه ستونِ جدید بزن: `volume`, `competition`, `note`.
   - 🎯 **تصمیم‌ساز:** کلماتی که **حجم بالا + رقابت پایین** → اولویتِ اولِ واقعی (جایگزینِ حدسِ فعلیِ P1/P2).

## بخش B — کشفِ کلماتِ جدید + نیمی از «شکافِ رقبا» (رایگان)
**همان Keyword Planner → «Discover new keywords»:**

1. تبِ **«Start with a website»** → آدرسِ رقیب را بده (اول `irmikro.com`، بعد `arghavannet.com`). گزینه‌ی «Use the entire site».
   - 🎓 این عملاً می‌گوید «گوگل این سایت را حولِ چه کلماتی می‌بیند» → نسخه‌ی رایگانِ Keyword Gap.
2. تبِ **«Start with keywords»** → این seedها را بزن: `میکروتیک`, `روتر میکروتیک`, `رادیو وایرلس`, `اکسس پوینت`, `آنتن وایرلس`, `لایسنس میکروتیک`, `mikrotik`.
3. کلماتِ **پرحجمِ کم‌رقابت** و به‌خصوص long-tailهای مدل‌محور و «قیمت/خرید X» را در یک فایل جمع کن (`data-import/keywords/discovered.csv`).

## بخش C — Authority و آف‌پیجِ رقبا (هدفِ اصلیِ تو از Semrush)
**ابزار ۱: Ahrefs Free Backlink Checker** (`ahrefs.com/backlink-checker` — رایگان، بدون اکانت لازم برای پایه).
**ابزار ۲: Moz Link Explorer** (`moz.com/link-explorer` — اکانت رایگان، ~۱۰ کوئری در ماه).

برای هر سه رقیب (irmikro, arghavannet, mrshabake) این جدول را پر کن:

| رقیب | DR (Ahrefs) | DA (Moz) | Referring Domains | لینک‌های واقعیِ قابل‌تکرار؟ |
|---|---|---|---|---|
| irmikro.com | | | | |
| arghavannet.com | | | | |
| mrshabake.com | | | | |

- ستونِ آخر مهم‌ترین است: به بک‌لینک‌های برترشان نگاه کن — آیا لینکِ **واقعی و قابل‌تکرار** دارند (دایرکتوریِ صنعتی، مقاله‌ی مهمان، رسانه)، یا فقط تلگرام و اسپم؟ اگر همه بی‌ارزش بود، یعنی **off-page زمینِ بازی نیست** و ما با on-page + سرعت + محتوا می‌بریم (فرضیه‌ی فاز ۲ تایید می‌شود).

## بخش D — صفحاتِ پرترافیکِ رقبا (سبک)
- **Ahrefs Free** بخشِ «Top Pages» محدودی دارد؛ اگر نبود، از **SimilarWeb (رایگان)** برای تخمینِ خامِ ترافیک و از `site:irmikro.com` در گوگل برای تعدادِ صفحاتِ ایندکس‌شده استفاده کن.
- هدف: ببین بیشترین ترافیکِ رقبا از **دسته** است یا **محصول** یا **مقاله** → تایید/اصلاحِ استراتژیِ «قطبِ محتوای آموزشی».

## بخش E — سیگنال‌های غیرمستقیمِ Authority (صفرهزینه)
برای هر رقیب: تعدادِ صفحاتِ ایندکس (`site:domain`)، سنِ دامنه (whois)، حجمِ سرچِ برندی (اسمِ برندش را در بخش A بزن). این سه با هم یک **رتبه‌بندیِ تقریبیِ Authority** می‌سازند بدون هیچ ابزاری.
