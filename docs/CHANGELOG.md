# CHANGELOG — حافظه‌ی مشترک بین چت‌ها

> این فایل «منبع حقیقت» مشترک است. هر چت اجرایی که کاری تمام کرد، یک خط اینجا ثبت می‌شود
> (توسط چت مدیر). قبل از شروع هر کار، این فایل + `marketing-seo-roadmap.md` را بخوان.

## ساختار چت‌ها
- **مدیر (چت اصلی):** معماری، رودمپ، سئو/مارکتینگ، کنترل کیفیت، صدور پرامپت. حافظه‌ی بلندمدت اینجاست.
- **چت الف — توسعه‌ی فنی:** فیچر/باگ بک‌اند و فرانت (RFQ، فید ترب، بهینه‌سازی، امنیت).
- **چت ب — دیتا/محتوا:** بازنویسی دسته/محصول/مقاله در پنل، ورود مشخصات و FAQ.

## قواعد
- برنچ کاری: `security-hardening` (master هدف PR نهایی).
- هر تغییر دیتابیس (فیلد جدید و…) حتماً همین‌جا ثبت شود تا چت‌های دیگر بدانند.
- دیپلوی تست: `mvn clean package -DskipTests` سپس `docker compose up -d --build`.
- سئوی این پروژه «غیرقابل‌خطا» است؛ هر تغییرِ صفحه‌ی عمومی باید SSR/متا را نشکند.
- **دروازه‌ی بازبینی محتوا (مدل سردبیر):** هیچ متن سئو/محتوایی (seoTitle/seoDescription، متن دسته، توضیح محصول، مقاله) قبل از تایید کاربر وارد پنل نمی‌شود. چت‌های محتوایی اول متن‌ها را برای بازبینی لیست می‌کنند، بعد از تایید وارد می‌کنند. تغییرات ساختاری بی‌خطر (slug، reparent، rename) نیاز به این دروازه ندارند.

## وضعیت زیرساخت (به‌روز: 2026-07-24)
- Stack: Spring Boot 3.5.6 / Java 17 / MongoDB (dev DB=masoud، prod DB=shopdb).
- انتیتی‌های محتوایی: Product (با techSpecs, faqs, relatedProductIds, slug/seo)، Category (slug/seo/position)، Article (بلاگ + hub/hubSlug).
- صفحات SSR: `/`، `/product/{slug}`، `/category/{slug}`، `/blog`، `/blog/{slug}`، `/blog/hub/{slug}`؛ + `/sitemap.xml`، `/robots.txt`.
- آنالیتیکس: GA4 فعال (G-4XZMGKFGD4)؛ رویدادها: view_item, add_to_cart, begin_checkout, purchase.
- امنیت: نوشتن‌های ادمین باید ROLE_ADMIN باشند. ✅ `POST/PUT/DELETE /api/v1/products` اکنون ADMIN است (رفع در 2026-07-23، کامیت 5d3d657).
