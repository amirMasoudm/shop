[چت توسعه‌ی فنی — تسک ۱۰ (کوچک، به‌موقع): فیلدِ alt اختصاصیِ تصاویر]

قبل از شروع `docs/CHANGELOG.md` را بخوان. **به‌موقع است:** چت ب همین حالا برای هر تصویر alt می‌نویسد ولی جایی برای ذخیره نیست و هدر می‌رود؛ بدونِ این فیلد باید بعداً ۲۷۶ محصول دوباره باز شود.

## خواسته (سبک، سازگارِ عقب — بدونِ مهاجرت)
1. **فیلدِ جدید** `List<String> imageAlts` در `Product` (موازیِ `images`، **هم‌ترتیب**، nullable/اختیاری). ⚠️ schema — در CHANGELOG ثبت شود.
   - **مهاجرت لازم نیست:** محصولاتِ قدیمی `imageAlts` ندارند → رفتار فعلی حفظ می‌شود.
2. `ProductRequest` + مپینگ در `ProductService` (تا از پنل ذخیره شود؛ خالی=null).
3. **پنل ادمین:** کنارِ هر تصویرِ گالری یک ورودیِ متنِ alt (هم‌ترتیب با آرایه‌ی تصاویر). `saveProduct` آن را بفرستد. ⚠️ مواظبِ باگِ دیتالاسِ تسک ۷ باش — چیزی را پاک نکن.
4. **رندرِ SSR:** برای تصویرِ i، اگر `imageAlts[i]` پر بود از آن استفاده کن؛ وگرنه **همان alt خودکارِ فعلی** (از name/seoTitle) — fallback حفظ شود.

## ⚠️ ریل
- SSR/متا/JSON-LD/گالری را نشکن؛ فقط منبعِ alt عوض می‌شود.
- سازگاری کامل با محصولاتِ بدونِ `imageAlts`.

## تحویل
- محصول با imageAlts → alt اختصاصی در HTML؛ بدونِ آن → alt خودکار (سالم).
- کامیت با pathspec صریح؛ schema (`Product.imageAlts`) در CHANGELOG ثبت شود.
