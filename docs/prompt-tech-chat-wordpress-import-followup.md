# پرامپتِ چت الف — پیگیریِ ۲۷۸ مقالهٔ ایمپورت‌شدهٔ وردپرس

طبقِ گزارشِ چت ج (۱۶ اوت)، ایمپورتِ وردپرس اجرا شده: ۲۷۸ مقاله روی سرورِ دوم به‌صورتِ درفت نشسته‌اند. دو چیز باید بسته شود:

1. **وضعیتِ مقالهٔ رتبهٔ‌۱ را چک کن:** مقالهٔ «عیب‌یابیِ میکروتیک به روشِ متخصصان» (طبقِ تصمیمِ ۱۴ اوت، `docs/prompt-tech-chat-wordpress-import.md`) باید جدا از بقیه، فوری QA و publish می‌شد — ۶۸٪ کلِ کلیکِ سایتِ قدیم مالِ همین یک مقاله بود. بررسی کن آیا این مقاله در پنلِ ادمینِ سرورِ دوم هست، فرمتش سالم است، و اگر هست منتشرش کن. اگر هنوز به این شکل جدا برخورد نشده، همین الان انجامش بده — منتظرِ صفِ ۲۷۸تایی نمان.
2. **۲ مقاله با ارجاعِ باقی‌ماندهٔ `wp-content`:** طبقِ گزارشِ چت ج، ۲ مقاله هنوز به تصاویرِ سایتِ وردپرسیِ قدیم لینک دارند (میزبانیِ مجدد طبقِ قدمِ ۴ پرامپتِ اصلی کامل نشده). این دو را پیدا و اصلاح کن قبل از publish کردنِ هیچ‌کدام.

بعدِ این دو، به مدیر گزارش بده: مقالهٔ رتبهٔ‌۱ منتشر شد یا نه، و وضعیتِ آن ۲ مقالهٔ مشکل‌دار.
