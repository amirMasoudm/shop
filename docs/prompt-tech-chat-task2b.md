[چت توسعه‌ی فنی — تسک ۲ب: رفع باگ غیرفعال‌نشدن فلش‌های منو در RTL]

قبل از شروع `docs/CHANGELOG.md` را بخوان. این ادامه‌ی تسک ۲ است (کامیت e3cc48a).

## گزارش QA (تاییدشده در مرورگر)
کارهای درست: فلش‌ها هنگام overflow ظاهر می‌شوند ✓، کلیک و غلتک موس اسکرول می‌کنند ✓، زیرمنوی fixed بعد از اسکرول درست باز می‌شود ✓.
**باگ:** فلش‌ها **هیچ‌وقت در دو انتها غیرفعال/محو نمی‌شوند**. تست شد: در scrollLeft=0 (ابتدا)، scrollLeft=-1004 (انتها) و وسط، هر دو فلش همیشه کلاس `visible` دارند. یعنی تابعِ به‌روزرسانیِ وضعیت فلش‌ها یا صدا زده نمی‌شود یا شرط مرزش در RTL همیشه true است.

## ریشه (RTL در کروم)
در حالت `dir="rtl"` کروم، `scrollLeft` از **۰** (ابتدا = راست‌ترین) تا **منفیِ** `(scrollWidth - clientWidth)` (انتها = چپ‌ترین) تغییر می‌کند. اگر شرط مرز با فرض مثبت‌بودن نوشته شده باشد، هیچ‌وقت درست تشخیص داده نمی‌شود.

## اصلاح خواسته‌شده
تابع به‌روزرسانی وضعیت فلش‌ها را این‌طور بنویس (RTL-safe):
```js
function updateMenuArrows() {
  const w = document.querySelector('.desktop-menu-wrapper');
  if (!w) return;
  const max = w.scrollWidth - w.clientWidth;        // مثبت
  const overflowing = max > 2;
  const pos = Math.abs(w.scrollLeft);               // 0..max در RTL کروم
  const atStart = pos <= 1;                          // راست‌ترین
  const atEnd   = pos >= max - 1;                    // چپ‌ترین
  // فلش راست = حرکت به سمت ابتدا (کاهش pos) → در ابتدا مخفی
  rightArrow.classList.toggle('visible', overflowing && !atStart);
  // فلش چپ = حرکت به سمت انتها (افزایش pos) → در انتها مخفی
  leftArrow.classList.toggle('visible', overflowing && !atEnd);
}
```
(اگر جهت فلش‌های تو با این نگاشت فرق دارد، فقط جای `rightArrow/leftArrow` را عوض کن — منطق atStart/atEnd همین است.)

این تابع باید صدا زده شود در: (۱) بعد از `renderDesktopMenu`، (۲) روی رویداد `scroll` نوار منو، (۳) روی `resize` پنجره، (۴) بعد از هر کلیک فلش (با کمی تاخیر برای اتمام smooth، یا داخل scroll listener که خودش کافی است).

## معیار پذیرش (در مرورگر داخلی تست کن)
- در ابتدای منو: فقط فلشِ سمتِ حرکت‌به‌انتها دیده شود؛ فلش دیگر محو.
- در انتهای منو: برعکس.
- وسط: هر دو دیده شوند.
- وقتی منو overflow ندارد (پنجره پهن یا دسته کم): هیچ فلشی دیده نشود.
- زیرمنوی هاور و اسکرول غلتک نشکنند.

کامیت با پیام فارسی گویا؛ نتیجه را گزارش بده.
