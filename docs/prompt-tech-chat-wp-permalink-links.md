# تسکِ چت الف (پیگیری) — لینک‌های داخلیِ `/20xx/xx/…` که ۴۰۴ می‌دهند

🔴 **این تسک بعد از `prompt-tech-chat-404-redirect-loop.md` انجام شود**، چون رفعِ
حلقه رفتارِ همین آدرس‌ها را عوض می‌کند و آزمونِ این تسک روی آن حساب می‌کند.

## نشانه

داخلِ متنِ بعضی مقالات، لینک به آدرس‌های پرمالینکِ وردپرسی مانده:

```
https://dadehnama.com/2025/05/01/mikrotik-introduction/     ->  404
https://dadehnama.com/2025/05/05/mikrotik-access-points/    ->  404
```

چت ب/F اول فرض کرده بود این‌ها ریدایرکت دارند؛ سنجید و نداشتند. من هم مستقل
سنجیدم: ۴۰۴ِ واقعی، صفر پرش.

## مقیاس — اندازه‌گیری‌شده، نه حدس

در نمونهٔ **۷۱ مقاله**، **۹ لینک** (۵ یکتا) از این جنس بود. یعنی مسئله‌ای کوچک و
پراکنده است، نه سراسری. بستهٔ F-۱ اتفاقاً غلیظ‌تر از میانگین بود (۱۴ لینک در
پنج مقاله).

**پس این تسک ارزشِ یک قاعدهٔ کوچک را دارد، نه یک مهاجرتِ بزرگ.**

## فرضیه‌ای که سنجیدم — نیمه‌درست است

دمِ آن آدرس‌ها معمولاً همان اسلاگِ یک مقالهٔ زنده است:

```
/2025/05/01/mikrotik-introduction/        ->  /blog/mikrotik-introduction        200 ✅
/2025/xx/xx/difference-between-dish-…/    ->  /blog/difference-between-dish-…    200 ✅
/2025/05/01/mikrotik-router-benefits/     ->  /blog/mikrotik-router-benefits     404 ❌
/2025/05/05/mikrotik-access-points/       ->  /blog/mikrotik-access-points       404 ❌
```

حدوداً **نیمی** از آن‌ها مقالهٔ متناظرِ زنده دارند و نیمِ دیگر ندارند (هیچ‌وقت
ایمپورت نشده‌اند یا اسلاگشان عوض شده).

## کارِ پیشنهادی

در `LegacyPathFallback`، **قاعدهٔ ۲** الان فقط مسیرِ **تک‌بخشی** را به‌عنوان اسلاگِ
مقاله امتحان می‌کند. یک قاعدهٔ خواهر اضافه شود:

> مسیرِ چهاربخشیِ `/{YYYY}/{MM}/{DD}/{slug}` (و سه‌بخشیِ `/{YYYY}/{MM}/{slug}`)،
> اگر `{slug}` اسلاگِ یک مقالهٔ منتشرشده باشد → ۳۰۱ به `/blog/{slug}`.

⚠️ **دقیقاً مثلِ قاعدهٔ ۲ از زنجیرهٔ `LegacyRedirect` هم رد شود** تا اگر اسلاگِ آن
مقاله بعداً عوض شد، یک‌پرشی بماند نه دوپرشی. همان کاری که قاعدهٔ ۲ می‌کند.

⚠️ `{YYYY}` و `{MM}` و `{DD}` باید واقعاً عدد باشند، وگرنه هر مسیرِ چهاربخشی
به این قاعده می‌افتد.

🟢 این یک قاعده است و هیچ ردیفی به دیتابیس اضافه نمی‌کند — همان فلسفه‌ای که در
جاواداکِ خودِ فایل نوشته شده: «یک قاعده صدها آدرس را برمی‌گرداند».

**آن‌هایی که مقالهٔ متناظر ندارند** بعد از رفعِ تسکِ قبلی ۴۰۴ِ صادق می‌گیرند، که
درست است. تصمیم دربارهٔ متنِ آن لینک‌ها (حذف یا تغییرِ مقصد) کارِ محتواست و به
چت‌های محتوا داده می‌شود، نه تو.

## آزمون

**باید ۳۰۱ِ یک‌پرشی بدهند:**

```
/2025/05/01/mikrotik-introduction/
/2025/05/01/difference-between-dish-and-sector-antenna/
```

**باید ۴۰۴ بدهند (نه حلقه):**

```
/2025/05/01/mikrotik-access-points/
/2025/13/99/chizi-ke-nist/            (mah-e 13 — adad-e bi-mani)
/2025/05/01/                          (bedun-e slug)
```

**نباید بشکنند:**

```
/blog/mikrotik-introduction           200|0
/shop/                                200|<=1
```

```bash
curl -sL --noproxy '*' -o /dev/null -w '%{http_code}|%{num_redirects}\n' --max-redirs 4 <URL>
```

⚠️ `mikrotik-introduction` و `difference-between-dish-and-sector-antenna` در
بستهٔ F-۲ هستند و به چتِ محتوا گفته شده **اسلاگشان را عوض نکند** تا این نقشه
باطل نشود. اگر دیدی عوض شده، به مدیر بگو.
