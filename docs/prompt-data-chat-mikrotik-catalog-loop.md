# پرامپتِ حلقه‌ای چت ب — پوششِ کاملِ کاتالوگِ میکروتیک

هدف: **همه‌ی ~۱۴۱ محصولِ میکروتیکِ باقی‌مانده** پروداکشن‌آماده شوند (بازنویسیِ کامل با محتوای غنی). اولویت‌بندی نداریم — کاتالوگ را ترتیبی جلو می‌رویم تا صفر شود. این پرامپت هر بسته تکرار می‌شود.

## هر دور (یک بسته)
1. **لیستِ باقی‌مانده را بکش:** محصولاتِ میکروتیکِ پنل که description یا techSpecs یا FAQ خالی/ناقص دارند. **۲۰ موردِ بعدی** را بردار (ترتیبی؛ تکراری‌نشده با بسته‌های قبل). — اندازهٔ بستهٔ استاندارد = ۲۰ (~۷ دور برای ۱۴۱).
2. **درفت** در `content-drafts/batch-<حرف>.md` با جدولِ پایش (مدل/دسته/آلوده/قیمت/منبع).
3. **خودچکِ ق۱–۱۲** (منبع mikrotik.com؛ فارسی‌اول؛ آلودگی‌زدایی؛ techSpecsِ ~۱۰ردیفی؛ دُمِ فارسیِ بی‌کاراکترِ خاص).
4. **ورودِ پنل:** alt/techSpecs/FAQ کامل، دامپِ specs حفظ. انتقالِ دسته (ق۷) اگر لازم.
5. **کامیتِ pathspec صریح** فقط روی فایل‌های خودت (نه CHANGELOG — مدیر می‌نویسد).
6. **گزارشِ چت:** تعدادِ زنده، انتقال‌های دسته، پرچم‌ها.

## پرچم‌ها (بدونِ بلاک، فقط علامت)
- 🚩 **قیمتِ صفر (ق۱۲):** وارد کن ولی پرچم بزن؛ کاربر دستی می‌زند.
- ⛔ **نبود در کاتالوگ:** مثلِ Cube/wAP — گزینه‌ها را بده، منتظرِ تصمیمِ مدیر/کاربر.
- 🔁 **رکوردِ تکراری:** مثلِ cAP ax/NetMetal — چکِ سفارش/عکس، انتقالِ عکس به اصلی، حذفِ تکراری.

## بعد از هر بسته
مدیر ممیزیِ سبک می‌زند (پرچم‌ها + ۱–۲ اسپکِ مشکوک از mikrotik.com) و در CHANGELOG ثبت می‌کند، بعد بستهٔ بعدی. **پیش‌رفت را با شمارنده گزارش بده** (مثلاً «۶۶/۱۹۷ زنده»).
