# تسک ۱۲ (چت الف) — سشنِ ادمینِ طولانی (تا چت ب مدام لاگین نکند)

## چرا
چت ب حجمِ زیادی کارِ پنل (ورودِ محصول) دارد و پیش‌فرضِ سشن (۳۰ دقیقه) باعثِ لاگینِ مکرر می‌شود. کاربر می‌خواهد لاگین کم‌تر تکرار شود.

## اصلِ حاکم (مهم — امنیت نشکند)
❌ **احرازِ هویت را برندار.** `SecurityConfig.java` **دست‌نخورده** بماند؛ همه‌ی `hasRole("ADMIN")`ها سرِ جایشان. این برنچ `security-hardening` است و پنلِ پراد باید محافظت‌شده بماند.
✅ فقط **عمرِ سشن و کوکیِ سشن** طولانی شود — کاربر همان یک‌بار لاگین می‌کند، ولی سشن هفته‌ها زنده و کوکی ماندگار می‌ماند (حتی بعد از بستنِ مرورگر).

## کار
در فایلِ کانفیگِ اسپرینگ (`src/main/resources/application.properties` یا `application.yml`) این دو مقدار را تنظیم کن (اگر نبود، اضافه کن):

```properties
# سشنِ ادمین طولانی — راحتیِ کارِ ورودِ محتوا (امنیت دست‌نخورده)
server.servlet.session.timeout=30d
server.servlet.session.cookie.max-age=30d
```

- `session.timeout=30d` → سشنِ سمتِ سرور ۳۰ روز بی‌فعالیت هم زنده می‌ماند.
- `cookie.max-age=30d` → کوکیِ سشن ماندگار می‌شود (بعدِ بستنِ مرورگر پاک نمی‌شود) پس لاگین بعدِ ری‌استارتِ مرورگر هم می‌ماند.
- اگر پروژه چند پروفایل دارد و می‌خواهی محتاط باشی، می‌توانی این دو خط را فقط در پروفایلِ dev بگذاری؛ ولی چون صرفاً عمرِ سشنِ یک کاربرِ **احرازشده** را زیاد می‌کند (نه بازکردنِ چیزی)، روی پراد هم بی‌خطر است.

## تست (سبک)
1. `mvn clean package -DskipTests` سپس `docker compose up -d --build`.
2. با ادمین لاگین کن → به `Admin.html` برو (باید ۲۰۰ بدهد).
3. کوکیِ سشن را در DevTools ببین: باید `Max-Age`/`Expires` داشته باشد (نه «Session»).
4. یک نوشتنِ ادمین (مثلاً ذخیره‌ی یک محصولِ تستی) → ۲۰۰.
5. **تستِ منفیِ امنیت (مهم):** یک `PUT /api/v1/products/{id}` **بدونِ کوکیِ لاگین** (مثلاً با curl) → باید همچنان **۴۰۱/۴۰۳** بدهد. اگر ۲۰۰ داد یعنی سهواً auth شکسته — متوقف شو و به مدیر بگو.

## کامیت
با pathspec صریح فقط فایلِ کانفیگ:
`git commit -- src/main/resources/application.properties` (یا `.yml`)
پیامِ کامیت: «تسک ۱۲: سشنِ ادمینِ طولانی (۳۰ روز) — کاهشِ لاگینِ مکررِ چت ب؛ امنیت/نقش‌ها دست‌نخورده».

## گزارش به مدیر
تاییدِ هر ۵ گامِ تست (به‌ویژه گامِ ۵ منفی) + کامیت‌هش.
