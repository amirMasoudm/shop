# پیشنهاد ساختار دسته‌بندی نهایی — نسخه‌ی تصمیم‌گیری

تاریخ: 2026-07-24 | وضعیت: ✅ **تاییدشده توسط کاربر (2026-07-25) — هر ۶ دسته + نگه‌داشتن دسته‌ی «اکسس پوینت عام»**. این ساختار مبنای بازطراحی پنل و نقشه‌ی کلمات است.

## مبنای تصمیم (سه ورودی تلاقی‌داده‌شده)
1. **کاتالوگ ما:** ۱۹۴ از ۲۷۶ محصول میکروتیک است، با زیرنوع‌های واضح: وایرلس آتدور (۵۹)، روتر (۴۳)، LTE (۲۹)، وایرلس ایندور (۱۹)، سوییچ (۱۸)، اکسسوری (۱۲). بقیه: ویپ (۱۹)، آنتن (۱۵)، انجنیوس (۱۱)، UBNT (۱۰)، میموسا (۵)، کمبیوم/لیگوویو/مایکروویو (کم).
2. **کوئری‌های GSC ما (اثبات‌شده):** «خرید روتر میکروتیک»، «رادیو وایرلس»، «لایسنس میکروتیک»، مدل‌ها (SXT LTE6، LHG 60G)، «رادیو کمبیوم».
3. **رقبا:** irmikro فقط برند-محور است (ضعف!)؛ arghavannet هم برند-محور هم نوع-محور دارد (روتر میکروتیک + رادیو وایرلس). الگوی برنده = **دوگانه**.

## اصل طراحی
میکروتیک را به‌عنوان «قطب برند» با زیردسته‌های **نوع-محور** می‌سازیم (چون هم عمق داریم هم کوئری دارد)؛ برای برندهای کوچک‌تر، **دسته‌ی نوع-محورِ عام** می‌سازیم و برند را فیلتر می‌کنیم (نه دسته‌ی جدا برای هر برند کوچک). این هم کوئری «روتر میکروتیک» را می‌گیرد هم «رادیو وایرلس» را.

## ساختار پیشنهادی (۲ سطح، ۶ دسته‌ی اصلی)

```
۱. میکروتیک (قطب)                     → /category/میکروتیک           [کوئری: قیمت میکروتیک]
   ├─ روتر میکروتیک                    → روتر-میکروتیک   (۴۳)  [خرید روتر میکروتیک ✓GSC]
   ├─ سوییچ میکروتیک                   → سوییچ-میکروتیک  (۱۸)  [خرید سوییچ میکروتیک]
   ├─ رادیو وایرلس آتدور میکروتیک       → وایرلس-اتدور-میکروتیک (۵۹) [رادیو وایرلس میکروتیک ✓GSC]
   ├─ اکسس پوینت (وایرلس ایندور)       → اکسس-پوینت-میکروتیک (۱۹) [اکسس پوینت میکروتیک]
   ├─ مودم و روتر LTE میکروتیک          → lte-میکروتیک   (۲۹)  [مودم LTE میکروتیک]
   └─ لایسنس و اکسسوری میکروتیک         → لایسنس-میکروتیک (۱۲)  [لایسنس میکروتیک ✓GSC]

۲. رادیو وایرلس (سایر برندها)          → /category/رادیو-وایرلس       [رادیو وایرلس ✓GSC، لینک نقطه‌به‌نقطه]
   (میموسا، کمبیوم، لیگوویو، انجنیوس، UBNT — برند = فیلتر)

۳. آنتن و دیش                          → /category/انتن-و-دیش         [آنتن وایرلس، دیش وایرلس] (۱۵)

۴. ویپ و تلفن تحت شبکه                 → /category/ویپ               [تلفن تحت شبکه، مرکز تلفن ✓GSC] (۱۹)

۵. اکسس پوینت و تجهیزات وایرلس داخلی    → /category/اکسس-پوینت         [اکسس پوینت — برندهای غیرمیکروتیک: انجنیوس/UBNT]

۶. تجهیزات پسیو و کابل شبکه            → /category/تجهیزات-پسیو       [کابل شبکه] (۵+)
```

## نکات کلیدی تصمیم
- **چرا برند کوچک = فیلتر نه دسته؟** میموسا ۵ محصول دارد؛ دسته‌ی مستقل با ۵ محصول از نظر گوگل «نازک» است. زیر «رادیو وایرلس» با فیلتر برند، هم صفحه‌ی قوی می‌سازیم هم «رادیو میموسا» را با فیلتر پوشش می‌دهیم. (اگر بعداً محصولات یک برند زیاد شد، ارتقا به دسته‌ی مستقل ساده است.)
- **هم‌پوشانی احتمالی:** دسته‌ی ۵ (اکسس پوینت عام) با «اکسس پوینت میکروتیک» زیرِ ۱. این عمدی است و هم‌نوع‌خواری نیست چون یکی برند-محور است یکی عام؛ ولی اگر ترجیح می‌دهی ساده‌تر باشد، دسته‌ی ۵ حذف و اکسس‌پوینت‌های غیرمیکروتیک هم زیر «رادیو وایرلس/آنتن» بروند.
- **تفاوت با ساختار فعلی:** الان دسته‌ها بیشتر برند-محور و پراکنده‌اند (۱۴ دسته‌ی سطح‌اول مثل سیسکو، لیگوویو با ۱-۲ محصول). این‌ها به فیلتر/زیرمجموعه تبدیل می‌شوند تا منو تمیز و هر صفحه‌ی دسته «چاق» شود.

## چیزی که از تو می‌خواهم

2. تصمیم درباره‌ی دسته‌ی ۵ (اکسس پوینت عام): نگه‌داریم یا ادغام؟
3. هر دسته‌ای که از دید بازارِ خودت کم/زیاد است.
