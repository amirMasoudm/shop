3. **خودچکِ ق۲–۱۲** (قانون ۱ در `product-content-standard.md` **ق۱ب** جایگزین می‌شود؛ ق۶ → **ق۶ب**؛ بقیه عیناً — فارسی‌اول ق۱۱، آلودگی‌زدایی ق۸، ضدِ دور-زدنِ ق۵ شاملِ منعِ دعوت‌به‌تماس، بدونِ HTML در description).
