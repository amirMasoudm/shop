# پرامپتِ حلقه‌ای چت ب — پوششِ کاتالوگِ VoIP

هدف: **~۵۴ محصولِ VoIP (Zayko/Fanvil/Yealink و مشابه)** پروداکشن‌آماده شوند. آخرین جیبِ باقی‌مانده از کاتالوگ.

## هر دور (یک بسته)
1. **لیستِ باقی‌مانده:** محصولاتِ ویپ بدونِ محتوایِ غنی. **۲۰ موردِ بعدی** (ترتیبی).
2. **درفت** در `content-drafts/batch-<حرف>.md` با جدولِ پایش.
3. **خودچکِ ق۲–۱۲ + قانون ۱ج/۶ب** (`product-content-standard.md`):
   - دسته: «ویپ و تلفنِ تحتِ شبکه» — **بدونِ زیردستهٔ برندی** (برخلافِ رادیو/سوییچ).
   - نام: کدِ کاملِ مدل (زایکو/Fanvil/Yealink با مدلِ کامل شناخته می‌شوند، خلاصه‌سازی لازم نیست).
   - منبعِ داده: `zycoo.com` (زایکو) / `fanvil.com` / `yealink.com`.
   - techSpecs تمرکز: تعدادِ خطِ SIP، PoE، صفحه‌نمایش، کدکِ صدا (G.711/G.722/G.729)، تعدادِ دکمه/BLF، HD Voice، (اگر بی‌سیم/DECT: بردِ آنتن).
   - ⚠️ ضدِ دور-زدن (ق۵)، بدونِ HTML در description، دقتِ عددی (بدونِ حدس) — همهٔ درس‌هایِ حلقه‌هایِ قبلی همچنان برقرارند.
4. **ورودِ پنل:** alt/techSpecs/FAQ کامل. اگر رکوردی هویتِ نامشخص/مغایرِ عکس داشت (مثلِ N2)، unpublish کن (نامِ «⛔ [تعلیق] ...»)، منتشر نکن.
5. **کامیتِ pathspec صریح.**
6. **شمارشِ نهایی: کوئریِ مستقیمِ DB** (نه جمعِ دستی) — طبقِ حافظهٔ `feedback-count-from-db`.

## پرچم‌ها
- 🚩 قیمتِ صفر (ق۱۲).
- ⛔ برندِ ناشناخته/هویتِ نامشخص.
- 🔁 رکوردِ تکراری (چکِ عکس، سایت سفارشِ واقعی ندارد).

## بعد از هر بسته
مدیر ممیزیِ سبک + ثبتِ CHANGELOG، بعد بستهٔ بعدی.
