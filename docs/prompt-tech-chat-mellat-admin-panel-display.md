# پرامپتِ چت الف — نمایشِ مرجعِ تراکنشِ ملت در پنلِ ادمین

⚠️ **این تسکِ بعدی است — بعدِ اتمامِ `docs/prompt-tech-chat-mellat-gateway.md` شروع کن**، چون به فیلدهایِ جدیدی که آن تسک به `Order` اضافه می‌کند وابسته است (`mellatRefId`، `mellatSaleReferenceId`، وضعیتِ `PAYMENT_FAILED`).

## زمینه
مدیرِ فروشگاه برایِ اطمینان از هر تراکنش، سه لایه دارد: پنلِ ادمینِ خودِ سایت (روزمره)، پنلِ خودِ به‌پرداخت (تطبیقِ دوره‌ای)، و حسابِ بانکی (سندِ نهایی). لایهٔ اول الان ناقص است چون شمارهٔ مرجعِ تراکنش هیچ‌جا نشان داده نمی‌شود — بدونِ آن، اگر روزی یک تراکنش مشکوک شد، مدیر چیزی برایِ دادن به پشتیبانیِ به‌پرداخت ندارد.

## کار
`src/main/resources/static/Admin.html`، تابعِ `viewOrderDetails(id)` (خط ۲۰۴۳-۲۰۵۶) همین الان جدولِ «مجموعِ کالاها / ۱۰٪ مالیات / مجموعِ فاکتور» را نشان می‌دهد. بعدِ ردیفِ «مجموعِ فاکتور» این دو مورد اضافه شود:

- **وضعیتِ پرداخت** — موفق / ناموفق و اگر ناموفق بود چرا (از وضعیتِ `PAYMENT_FAILED` که در تسکِ ملت اضافه شد).
- **`mellatRefId`** و **`mellatSaleReferenceId`** — فقط اگر مقدار داشتند نمایش بده.

⚠️ سفارش‌هایِ قدیمی‌تر (ساخته‌شده با mock-gatewayِ قبلی، قبل از این تسک) این فیلدها را ندارند — برایشان `---`/خالی نشان بده، نه خطا یا `undefined`.

جدولِ لیستِ سفارش‌ها (`renderOrdersAdmin`, خط ۱۹۵۸-۱۹۹۳) نیازی به تغییر ندارد؛ فقط نمایِ جزئیات کافی است.

## تست
یک سفارشِ پرداخت‌شده (از تسکِ قبلی) باز کن → مرجعِ تراکنش و وضعیت درست دیده شود. یک سفارشِ قدیمی/mock هم باز کن → خطا ندهد، فقط خالی نشان دهد.

## گزارش
یک خطِ کوتاه در چت کافی است.
